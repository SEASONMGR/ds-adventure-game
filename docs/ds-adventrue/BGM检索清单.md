## 三、第 14 首是核心（庆功曲）

它不只是"结局曲"—— 剧本里它出现在：
- 第 3 章 合鳞礼
- 终章 把庆功曲放进秤盘
- 真结局（完整编制版 `bgm_ending_true`）
- 第 8 章 ds娘内心（慢板变奏 `bgm_whale`）

**挑法建议**：先只挑第 14 首，挑到"能记住、能跟着哼"的那首之后，再挑其它 13 首
（其余曲目最好在配器上向它靠拢，整套听起来才像一张原声带而不是拼盘）。

## 四、交付给我的方式

三种都行：
1. 直接把音频文件放进 `D:/applications/comfy-ui/runtime/galgame-assets/bgm/`（我按上表重命名）
2. 给我 14 个下载链接
3. 给我站点上的曲名 + 作者名（我去取）

我收到后会做：**重命名 → 转 OGG（128kbps）→ 检测/标记无缝循环点 → 统一响度到 -16 LUFS → 归档到 `assets/sounds/` → 写 `CREDITS.md` 署名**。

## 五、接线（BGM 到位后）

引擎的音频节点：

```
{
type = music
x = 0
y = 0
audio = assets/sounds/bgm_daily.ogg      ← 把现在的 demo 路径 resources/audio/theme.wav 换掉
}
```

全篇 4 个 `music` 节点目前都指向 demo 路径，替换时改 `audio` 即可。
