# 部件化分层 · 命名对照表

> 供剧本/引擎引用。目录：`assets/sprites/layers/<角色id>/`
> 生成脚本：`runtime/galgame-assets/make_layers.py`　校验：`check_layers.py`

## 一、文件结构

```
assets/sprites/layers/<角色id>/
├── body.png           身体层：整幅立绘，**脸部矩形区域为透明**（所有表情共用这一张）
├── face_<表情>.png    脸部部件：脸部矩形区域（含羽化边），与 body.png 同画布
├── fx_blush.png       情绪层 · 腮红
├── fx_sweat.png       情绪层 · 汗滴
├── fx_tears.png       情绪层 · 泪痕
├── fx_shadow.png      情绪层 · 刘海投影/眼下阴影
└── _meta.json         画布尺寸、脸部矩形、表达式清单、校验结果
```

## 二、引擎用法

`body` 与 `face_*` **同画布**（1024×1536），所以叠放时 **x / y 相同**，按节点顺序叠加即可：

```
{ type = char  id = ds_body  x = 480  y = 150  width = 320  height = 520
  path = assets/sprites/layers/ds/body.png }
{ type = char  id = ds_face  x = 480  y = 150  width = 320  height = 520
  path = assets/sprites/layers/ds/face_weary.png }
{ type = char  id = ds_fx    x = 480  y = 150  width = 320  height = 520
  path = assets/sprites/layers/ds/fx_tears.png }
```

**换表情只替换中间那张** —— body 不动，因此跨表情的身体/服装**绝对一致**（这是分层的全部意义）。

## 五、脸部矩形是怎么来的（自校准）

1. 取该角色的**面部 inpaint 合成图**（`runtime/galgame-assets/inpaint/official_*/`）
   —— 这些图在遮罩外**逐字节相同**
2. 计算所有表情之间的**像素差异包围盒** = 脸部区域（不需要手工记坐标）
3. 外扩 12px 作为矩形，对**整幅抠图**（未裁切，与合成图同坐标系）做切分
4. 校验：矩形外 RGB 与 alpha 必须逐字节相同

**踩过的坑**：不能用紧裁切后的立绘做分层 —— 它与合成图坐标系不同（1024×1536 vs ~809×1444），
矩形会整体错位；也不能用逐张 rembg 的抠图差异来推矩形（边缘 matte 噪声会让包围盒涨到整幅图）。
