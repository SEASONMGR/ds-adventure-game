# 用户 Pixiv 收藏画风分析（D:\applications\resilio sync\pixiv，82 张）

> 用途：作为本作 CG / 背景的**画风基准**。分析基于 82 张全量总览（`preview/pixiv_sheet_1~3.png`）。

## 一、整体定位

**日系唯美氛围插画 · 电影感半厚涂**（Pixiv 2025 年前后的主流审美）。

不是纯赛璐璐平涂，也不是写实厚涂 —— 是"**光与色驱动**"的插画：画面好看的第一因是光影氛围，其次才是角色精细度。情绪基调统一是：**安静、怀旧、夏日感、旅途感、微伤感**（"美しい"型，不是"燃"也不是"涩"）。

## 二、色彩与光影（第一特征）

| 特征 | 表现 |
|---|---|
| **光即主角** | 每张图都有明确的光源叙事：夕阳逆光 / 窗光斜射 / 雨夜霓虹 / 月光 / 天光 / 台灯光 |
| **互补色对撞** | 反复出现 **青蓝·靛紫 ↔ 橙金·暖黄**；红白 ↔ 深蓝；紫 ↔ 黄绿 |
| **单色主题化** | 一张图常锁定一个色系：纯蓝泳池、金黄麦田、纯白雪山、黑白废墟灰调 |
| **暗部有层次** | 暗部用冷色填、不透不糊；从不用纯黑压暗 |
| **高光语言** | 头发/水面/眼睛强高光；空气感（光斑、尘埃、水汽、雨丝） |
| **饱和度** | 高饱和但不过曝，灰调过渡自然 |

## 三、技法特征

- **半厚涂**：笔触可见、材质有颗粒（石材、木纹、布料、草地），靠色块塑形而非靠线
- **线条**：细、软、局部无线；少量作品是线稿向（黑白废墟、猫剪影、单色雪景）
- **质感重点**：花草、水面倒影、布料褶皱、发丝分层、发光体
- **分辨率高**：多为大画幅（收藏里最大 12MB）

## 四、构图习惯

- **两极分化**：
  - ① **广角环境人像**（人物只占 10~30%，场景是主角）—— 这是主流
  - ② **情绪特写**（脸占 60%+，背景极简或纯色）
- **天空占比大**（1/3 ~ 1/2 都是天）
- 常用**框景**（拱门、窗、栏杆、隧道口）、**对称**（神殿、泳池、走廊）、**引导线**（路、栏杆、光柱）
- 大量**背影/侧脸/远小人物**，避免直视镜头的"证件照"感

## 五、题材偏好（出现频率排序）

1. **夏日青春**：蓝天白云、向日葵、泳池、校服、自行车、蝉鸣感
2. **花与水**：几乎每三张就有一张有花或水（海/泳池/雨/湖面倒影）
3. **和风东方**：红白巫女、和服、神社石灯、纸伞、莲花、榻榻米
4. **废墟遗迹**：神庙残柱、雪中城市、水下城市、末世阶梯
5. **都市夜**：霓虹、雨夜街道、电车、房间内景、工作室
6. **角色**：原创为主；IP 出现频率最高的是**东方系**（灵梦/红白巫女）、**芙莉莲**、**初音**、FGO
7. 也收藏**角色设定稿/多视图**（做参考用）

## 六、对项目的可执行结论 ★

### 6.1 CG 的正确做法
**氛围 > 角色**。不要做"角色特写堆细节"，要做**广角环境人像 + 强光源叙事**：

```
构图：人物占画面 20~30%，场景占主体；或用框景（拱门/窗/栏杆）
天空：占 1/3 以上
必加：光源（夕阳/窗光/霓虹/月）、水面或反光、花草植物、光斑尘埃
```

### 6.2 配色公式
```
主色：青蓝 / 靛紫 / 深蓝
对撞色：橙金 / 暖黄 / 朱红
暗部：冷色填充（不用黑）
高光：发丝 / 水面 / 眼睛
```

### 6.3 要避免的
- 纯平涂赛璐璐（太"廉价感"）
- 纯白背景 + 无光源的平铺光（立绘可以，CG 不行）
- 角色占满画面 80% 的"大头照"CG
- 过曝的高光、糊死的暗部

### 6.4 画师 tag 方向
用户的收藏属于"**Pixiv 唯美氛围系**"画师群 —— 与我之前实测的 `hiten / ke-ta / miv4t / ask` 是同一谱系。
