## 建议的统一色板

游戏美术整体是**深蓝底 + 青蓝高光 + 暖金点缀**（见 `画风分析-用户收藏.md`），小游戏棋盘建议向它靠拢：

| 用途 | 建议值 | 说明 |
|---|---|---|
| 棋盘/场地底 | `#0d1020` → `#121a2b` | 与 UI 套件同色系 |
| 格线/描边 | `#ffffff` @ 0.10~0.20 | 保持通透，别用实线 |
| 主要元素（蛇身/我方棋子/方块） | `#4fd1c5` ~ `#7ee787` | 青绿，呼应数据世界 |
| 次要元素/对手 | `#c95a7a` ~ `#e06c75` | 暖红，与青绿对撞 |
| 高光/选中 | `#ffd76a` | 暖金，与标题美术字同色 |
| 危险/警告 | `#ff8a5c` | 砖块/雷区 |

> 若走**路线 B（加载贴图）**，则不需要改颜色，改用成套 PNG 精灵图；
> 两条路的取舍见 `UI与小游戏接线规格.md` §3。
