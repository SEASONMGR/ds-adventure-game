## I. 目录结构与命名规范（按 `优质资产的要求.md`）

```
assets/
├── characters/
│   └── <角色id>/                        # ds / glm / qwen / kimi / dengguan / qiguan / xiguan ...
│       ├── base.png                     # 基础身体（姿势 01）
│       ├── costume_<n>/                 # 服装编号（01=默认）
│       │   ├── base.png
│       │   └── <表情>.png               # 表情差分
│       └── layers/                      # 部件化（引擎动态合成用）
│           ├── face_<表情>.png          # 脸部部件（透明 PNG，含 alpha）
│           └── fx_<腮红|汗|泪|阴影>.png # 情绪图层，可独立叠加
├── backgrounds/  ui/  cg/  audio/  minigames/
```

**命名**：`<角色id>_<服装编号>_<姿势编号>_<表情编号>.png`
例：`glm_01_01_05.png`（GLM娘·默认服装·站姿·第5表情）
**交付**：透明 PNG-24（必需）+ 分层 PSD（源文件）+ 资产清单 + 命名对照表
**规格**：立绘高 ≥1080px（当前 ~1500px ✅）；CG 3840×2160；RGB
