## 二、小图标（参考图里的"点缀"不能省）

参考图每个组件都带小图标，本主题按同样思路落进地图（都是独立的 `text` 节点，鼠标穿透、不影响点击）：

| 图标 | 字符 | 颜色 / 字号 | 位置 |
|---|---|---|---|
| 名牌左侧菱形 | `◆` | `#8fd0ff` / 14 | 名牌左侧 `+14, +12`（名牌文本左侧留白 40 挡住不重叠） |
| 选项按钮左尖角 | `‹` | `#8fd0ff` / 22 | 按钮内左侧 `+16` |
| 选项按钮右尖角 | `›` | `#8fd0ff` / 22 | 按钮内右侧 `-40` |
| 章节横幅端点 | `◆` | 同文本色 | `◆ 标题 ◆`（横幅无图时的文字回退版） |

> 选 `‹ › ◆` 是因为：项目 UI 字体是 **Microsoft YaHei UI**，实测它有 `‹ › « » ◆ ＜ ＞ 〈 〉`，
> 但**没有** `❮ ❯ ◀ ▶ ⟨ ⟩`（会渲染成豆腐块）。换字体的话记得重新确认这几个字形。

## 三、主题落在哪几个文件（改主题只动这三处）

| 文件 | 管什么 |
|---|---|
| `tools/build_story.mjs` → `UI` 常量 + `DIALOG_STYLE` / `NAME_STYLE` / `NAME_ICON_STYLE` / `CHEVRON_STYLE` / `endingStyle()` | **地图里的静态外观**：对话框、名牌（含菱形图标）、选项按钮两端尖角、结局卡/遮罩、横幅回退；改完 `node tools/build_story.mjs` 重新生成地图即可 |
| `src/main/resources/styles/player.css` | **交互态与全局**：`.story-btn`（normal / hover / pressed）、`.dialog-panel`、`.name-plate`、`.toast`、菜单与浮层、设置滑条、JavaFX 原生弹窗 `.dialog-pane` |
| `src/main/java/com/studio/reader/ReaderView.java` | 对话框**四角角括号**（`DIALOG_BRACKET_COLOR` = `#8fd0ff`，4 个鼠标穿透的 Region，`Insets(3)`、21×21、2px） |

> 为什么按钮不在地图里写样式：JavaFX 的**内联样式优先级高于样式表**，一旦把 `-fx-background-color` 写进节点，
> `player.css` 里的 `:hover` / `:pressed` 就再也盖不上去了（hover 反馈会消失）。所以按钮只由 CSS 定色。

## 五、换主题 / 加皮肤

1. 改 `UI` 常量与 `player.css` 里的色值 → 重新生成地图（`node tools/build_story.mjs`）；
2. 角括号颜色同步改 `ReaderView.DIALOG_BRACKET_COLOR`；
3. 想给**单张地图**单独换肤：地图节点上的 `style` 会覆盖 `player.css`（内联优先），
   直接在该地图的节点里写 `style = …` 即可（代价是该节点的 hover 态同样会被覆盖）。

## 六、怎么验证（截图核对）

开播放器 → 跳场景 → `ReaderView.snapshot(File)` 存 PNG，再逐张与参考图局部放大图对比。核对过：
起始对话框（角括号贴边、名牌含菱形图标）、选项按钮 normal/**hover**（含两端尖角）、横幅、坏结局（品红 + 遮罩）、真结局（冷蓝）、系统提示。
自动化：`mvnw.cmd -B test` 全过、素材引用 0 缺失、启动日志无 CSS 解析错误。
