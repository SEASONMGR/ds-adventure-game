# 小游戏素材需求清单（风格统一 + 剧情联动 · 第一轮）

| 项 | 值 |
|---|---|
| 提出方 | 程序侧 |
| 日期 | 2026-09-14 |
| 背景 | 9 个小游戏目前是**纯代码绘制 + 游戏内无声**，要做统一外壳与逐动作反馈 |
| 结论 | **大部分 UI 素材可复用已交付件**（见 §四）；真正需要新出的是**音效**（§二）与**少量图标**（§三） |
| 规格基准 | 音频 **WAV / 44100Hz / 单声道 / 16bit**（与已交付 `se_*.wav` 一致）；图像 **PNG-24 带透明（RGBA）**，按表内尺寸交付、**不要放大** |

## 一、优先级说明

- **P0**：本轮（统一外壳 + 逐动作反馈）必需，缺了会明显"哑/生硬"
- **P1**：明显提升手感，建议同批出
- **P2**：可选／锦上添花，可与下一轮一起
