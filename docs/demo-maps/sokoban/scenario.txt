#  推箱子小游戏 —— 验收用演示地图（事件 ID: sokoban）
#
#  用法：启动播放器 → 菜单「打开地图文件夹…」→ 选中本目录
#        进入 Start 场景会自动把小游戏嵌入主舞台中央，
#        点标题栏的【← 返回剧情】即可回到剧情。
#
#  玩法：
#    · 方向键 / WASD 移动，把箱子推到金色目标点上
#    · 人能推不能拉，一次推一个；箱子抵墙或抵箱子就推不动
#    · Z 撤销，R 重玩本关；全部箱子归位即过关
#    · 内置 3 关，全部经 BFS 穷举验证必定有解
#
#  剧情出处：第 8 章「数据搬运大作战」—— @minigame sokoban mode:normal
